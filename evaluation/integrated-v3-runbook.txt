Four-rank A/B/C evaluation tools — 2026-11-18

Scope
Protocol HybridSpotDDP-E1E2-ABC-all4rank-v3-20261118. E1=A/B, E2=A/B/C.
One rank and one GPU on each of four same-type VMs in aws1/ap-northeast-2c.
A=4OD, periodic checkpoint disabled, no planned fault. B/C use the same
existing policy, risk sequence, training contract and adaptive checkpoint
configuration. Only C dispatches one pinned, UID-owned Spot FIS interruption
at the predeclared50% common committed optimizer-step threshold. A/B results
may be shared by E1/E2 when their full contract is identical, never counted
as independent repeats. An acceptance diagnostic is not a formal A/B/C result.

FIS C only
Use evaluation.final_fis plan/start CLI (see --help) with the run directory,
explicit reviewed role/healthy OD stop alarm and exact run confirmation.
Before starting training, record fis_target_instance_id (lexically first
initial owned Spot NP) and fis_stop_alarm_instance_id (rank0 OD), and retain
initial_instance_ids. No substitute target is allowed. Live validation checks
all four current Pod UIDs/GPU limits/distinct owned nodes, a complete durable
checkpoint of those same current UIDs, frozen live spec hash, current common
step, original provider pool, account/type/AZ/markets and remaining recovery
reserve. FIS uses exactly1 ARN, PT2M notice and one atomic start intent. An
ambiguous response requires reconciliation, never a blind retry. A missing
checkpoint at the predeclared fault makes that attempt ineligible; do not shift
the trigger to a later convenient checkpoint.

The primary denominator is source NodeRequest creation -> all4 goal optimizer
updates, including startup/CP/recovery. Completion hashing/audit/return time is
billed but does not move the useful training-completion boundary. Replayed
steps and duplicate observations do not increase useful work. ResNet reports
samples, GPT2 tokens. All4 goal/completed and final parameter/optimizer/data
contract digests are required; rank-local ResNet BN buffers remain separate.
Metrics are candidates requiring protocol/deviation review, never automatically
formal scientific results. The historical T_training throughput is secondary.
GPU Compute Cost is not total cloud cost. EBS/NFS/VPN/network/FIS/management
cost exclusions and termination polling uncertainty must be disclosed.
